# ✍️ AI ライティングツール

Python + Streamlit + Gemini API で作った、個人用のライティング支援ツールです。
データベース・ログイン認証なし。ローカルで動かすだけで使えます。

## 搭載機能

| 機能 | 内容 |
|---|---|
| 📝 ブログ記事 | テーマ・キーワード・文字数から、見出し付きの記事を執筆 |
| 📧 メール返信 | 受信メールを貼り付けて、件名つきの返信文を作成 |
| 📄 要約 | 長文 / PDF を、箇条書き・議事録形式など目的別に要約 |
| 🔍 校正・リライト | 誤字脱字チェック、読みやすさ改善、文体変換 |
| 📱 SNS投稿 | X / Instagram / LinkedIn 等の作法に合わせた投稿文を複数案 |
| 💡 タイトル・コピー | 記事タイトル、件名、キャッチコピーを狙い付きで一覧化 |
| 🌐 翻訳 | 日英中韓の自然な翻訳。文体指定・用語集・訳注に対応 |
| 🧠 アイデア出し | 記事ネタ・構成案のブレインストーミング |
| 💬 チャット | 上記に当てはまらない相談用の対話モード |
| 🕘 履歴 | 生成結果をローカル保存・検索・エクスポート |

どの機能でも共通で使えること:

- 生成中のストリーミング表示
- 結果の `.md` / `.txt` ダウンロード、コピー用テキスト
- 「もっと短く」などの**修正指示による書き直し**
- モデル・創造性(temperature)・高速モードの切り替え

## セットアップ

### 1. APIキーを取得

[Google AI Studio](https://aistudio.google.com/app/apikey) で Gemini の APIキーを取得します（無料枠あり）。

### 2. キーを設定

```bash
cp .env.example .env
# .env を開いて GEMINI_API_KEY=取得したキー に書き換える
```

`.env` を作らず、アプリのサイドバーに直接貼り付けて使うこともできます。

### 3. 依存パッケージをインストール

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4. 起動

```bash
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。
2回目以降は `./run.sh` だけで起動できます。

## ディレクトリ構成

```
PythonAI_app/
├── app.py                # エントリーポイント（ページ登録とサイドバー）
├── run.sh                # 起動ショートカット
├── core/
│   ├── config.py         # APIキー・モデル・生成パラメータ
│   ├── gemini.py         # Gemini API ラッパー（ストリーミング / エラー変換）
│   ├── prompts.py        # 機能ごとのプロンプト定義  ← 出力の質を変えるならここ
│   ├── history.py        # 履歴の保存（JSON Lines）
│   └── ui.py             # 共通UI（生成・結果表示・ファイル読み込み）
├── views/                # 画面1つ = ファイル1つ
└── data/history.jsonl    # 生成履歴（gitignore 済み）
```

## カスタマイズのヒント

- **出力の調子を変えたい** → `core/prompts.py` の各関数の `system` を編集
- **機能を追加したい** → `core/prompts.py` に関数を1つ足し、`views/` に画面を1つ作り、`app.py` の `PAGES` に登録
- **新しいモデルを使いたい** → サイドバーのモデル欄で「カスタム（手入力）」を選び、モデル名を直接入力

## 注意

- APIキーは `.env` に置き、Git にコミットしないでください（`.gitignore` 済み）。
- 生成結果に含まれる固有名詞・数値・日付は、公開前に必ず自分で確認してください。
